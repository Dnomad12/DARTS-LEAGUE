# Darts League — GitHub Pages Standings (in /docs)

This directory contains a simple static GitHub Pages site that displays darts standings from a JSON data file.

Files added under docs/
- index.html — main page
- assets/js/standings.js — client-side renderer
- data/standings.json — JSON data source (edit this file to update standings)

To publish the site:
1. In the repository Settings → Pages, set Source to: Branch: main, Folder: /docs, then Save.
2. Wait a minute and visit: https://dnomad12.github.io/DARTS-LEAGUE/

If you want different styling, automatic updates from a CSV, or integration with your shuffleboard site look, tell me and I can update the site.
