docs/uploads/ — Upload screenshots for OCR

Place your scoreboard screenshots in this folder using GitHub's web UI or by pushing via git. Recommended filenames: shot1.png, shot2.jpg, etc.

How to upload via GitHub web UI:
1. Go to: https://github.com/Dnomad12/DARTS-LEAGUE
2. Click "Add file" → "Upload files".
3. Drag your images into the file chooser and set the target path to "docs/uploads/".
4. Commit directly to master with a short message like "Add OCR sample screenshots".

Notes:
- Files committed here will be public if the repository is public.
- If you prefer private uploads, do not commit them to the repository; instead provide them in this chat or use a private file host.

After you upload, reply here with the filenames (e.g. docs/uploads/shot1.png) and I will inspect them and update the OCR parser accordingly.
